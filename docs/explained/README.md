# Machina Christi, explained

These pages explain how the site works and how it gets built, in plain words,
for someone with no technical background. They are part of the project, not an
afterthought: every phase of work adds to them.

- **[foundations.md](foundations.md)** — the basic ideas of software (server,
  API, cache, test, deploy, and so on), each in a few sentences with an everyday
  comparison. Start here if a word in any other page is unfamiliar.
- **One page per phase or big feature**, written when the work is finished:
  - [Phase 1 — the website that knows what day it is in the Church](phase-1-season-api.md)

How to read them: you don't need to read code. Where a file is named, it's only
so you can find it later; the explanation never depends on it.
